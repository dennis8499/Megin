# Megin project knowledge

Read [repository-workflow.md](../megin/references/repository-workflow.md) for root/resume and reference selection,
then [language-policy.md](../megin/references/language-policy.md) for human-readable output.

Inspect established docs before choosing a format/location. Durable knowledge belongs in
each selected Repo; work progress belongs in the selected root's Work ID. Preserve source
provenance, version, confidence and open questions in architecture/operations/decision records.
Chat assertions or passing tests alone cannot establish source authority.

For updates, plan approved paths/checks, apply alongside implementation, then review and
verify as product files. Group records may link approved cross-Repo facts. Reconcile/promote
knowledge only after human acceptance. Finish with evidence-backed results or accepted,
verified documentation changes within scope; unrelated Repos/docs remain outside the task.
